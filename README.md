# YZL 启动器 · Your Zone Launcher

仿 PCL 风格、面向生电玩家的 Minecraft Java 版第三方启动器。

- 深色玻璃渐变 UI、启动画面、自绘渐变大按钮、自定义标题栏
- 全量 Java 版历史版本列表（920 个版本）
- 模组中心：Modrinth 数据源，内置生电精选（Carpet/Lithium/Starlight…）
- 一键安装 Fabric，BMCLAPI 国内镜像加速
- 离线账户、多线程下载、实时控制台

## 构建 Windows 独立安装包

GitHub Actions 已配置：推送到 main 自动在 windows-latest 上构建 exe + Inno Setup 安装包并发布 Release。
也可本地：安装 Python 后运行 build.bat。
